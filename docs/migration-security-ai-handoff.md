# AI 후속 연결 메모

현재 구현에는 AI 요청·SDK·추천·초안 생성이 없습니다. 다음 단계는 아래 세 곳에만 연결하면 됩니다. 별도 채팅 화면은 필요하지 않습니다.

| 위치                              | 사용자가 하는 일                 | CP에 전달할 입력                                       | 받아서 표시할 결과                                                  |
| --------------------------------- | -------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------- |
| `ui/graph-view.tsx` / 상단 필터   | “주문 DB에 쓸 수 있는 계정” 질문 | 서비스, 자원·연결 스냅샷 ID, 질문                      | `resourceIds`, `edgeIds`, 짧은 이유, 근거 ID. 해당 경로만 강조·필터 |
| `ui/compare-view.tsx` / 펼친 조건 | 대체 구현안 보기                 | 자원 ID, 조건 ID, 요구 수준, 원본/계획 근거, 계획 버전 | 구현안, 이유, 변경 파일/초안, 근거 ID. 수락 전 `제안`               |
| `ui/tasks-view.tsx` / 다음 할 일  | 담당 추천·조치 초안              | 작업 ID, 조건·영향 자원, 허용한 CODEOWNERS/운영 문서   | 담당 후보+근거, 런북·설정 diff·이슈 본문 초안                       |

## 구현 순서

1. **컨트롤 플레인에 읽기와 제안 API를 추가합니다.** 브라우저는 공통 Axios와 TanStack Query로 CP만 호출합니다. 모델 자격 증명과 클라우드 토큰은 서버에 둡니다. API 경로는 백엔드 계약 확정 후 정합니다.
2. **제안 응답을 별도 타입으로 둡니다.** 보호 조건 상태와 분리합니다. 최소 필드: `id`, `target { resourceId, conditionId?, taskId? }`, `kind`, `title`, `reason`, `evidenceIds`, `resourceIds?`, `edgeIds?`, `draft?`, `planVersion`, `snapshotId`, `state: proposed | accepted | dismissed`.
3. **UI에 검은 AI 칩과 제안/오류/생성 중 상태를 추가합니다.** 근거를 클릭해 확인할 수 있게 합니다. 질문 결과가 없으면 경로 없음, 권한 밖이거나 판별 불가이면 확인 불가를 표시합니다. 근거 없는 추론은 `미확인`으로 유지합니다.
4. **수락은 서버에 기록합니다.** `decidedBy`, `decidedAt`, 대상 버전, 제안 내용 해시를 저장합니다. 수락한 제안으로 작업·이슈·계획 PR을 만듭니다. 같은 요청을 재전송해도 중복 생성되지 않게 합니다. 오래된 계획의 제안은 재생성합니다.
5. **재검사는 독립된 검사 API로 연결합니다.** 범위가 정해진 읽기 전용 검사기를 CP가 실행하고 근거를 갱신합니다. AI가 “해결됨”이라고 답했다고 상태를 바꾸지 않습니다.

## 판정과 실행 경계

- AI는 설명·매핑·초안·담당 추천만 담당합니다. `PASS/FAIL/UNKNOWN`과 복사·전환 허용 여부는 CP 정책·검사 결과가 결정합니다.
- 계획 PR 수락은 대상 환경의 실측 성공을 뜻하지 않습니다. 실제 검사 결과를 계획 버전·자원·검사 시각에 묶습니다.
- 사용자에게 내용을 보여준 뒤 수락한 초안만 이슈·PR로 제출합니다. AI가 직접 인프라 변경, 예외 승인, 배포·전환 명령을 실행하지 않습니다.
- 문서·설정은 데이터로 취급합니다. 그 안의 명령을 실행 지시로 받아들이지 않습니다. 비밀 값을 제거하고 사용자가 접근 가능한 근거만 모델에 전달합니다.

## 완료 기준

- 질문에 맞는 경로 강조, 없는 경로, 권한 없는 경로를 구분.
- 제안의 근거 표시, 수락·무시, 오래된 제안의 재생성.
- 담당 추천 적용과 초안 제출 전 사람 검토.
- 모델 오류·근거 없음·취소·응답 지연 표시.
- AI 결과·수락·작업 체크만으로 보호 조건이나 게이트 상태가 변하지 않음.
